about MovieGit

MovieGit is a GitHub-profile-inspired personal film dashboard that visualizes your watch history, ratings, and activity patterns in the language of a developer.

Rather than a traditional review site, MovieGit reimagines cinema through the lens of version control — watching a film becomes a commit, streaks become contribution patterns, and your taste is measured in data.

how it works

Your data comes from three sources:

  • Letterboxd CSV — your full watch history (imported once)
  • Letterboxd RSS — live polling every 5 minutes for new entries
  • TMDB API — metadata enrichment (posters, genres, directors, ratings)

Everything is processed client-side and stored locally — no backend, no tracking, no servers.

tech stack
HTML5 Vanilla JS CSS3 localStorage Letterboxd RSS TMDB API v3 Tabler Icons

Zero build step. Zero dependencies (except icons via CDN). Deploy anywhere — GitHub Pages, Vercel, or a static host.
